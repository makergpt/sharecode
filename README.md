# Sharecode

Open-source code repository for my Sharecode app, built with Base44.

## Source code

Selected snippets from the **View Source Code** panel on [sharecode.base44.app](https://sharecode.base44.app/) are in [source-code.md](source-code.md). The panel does not expose the full app source.

To sync the complete project, connect Sharecode to this repository from the Base44 editor using **GitHub connection**. Base44 currently shows that connection as a Builder-plan feature. Its [GitHub integration guide](https://base44.com/blog/base44-github-integration) explains the setup.

Review the source and remove secrets or private data before publishing the full project.
