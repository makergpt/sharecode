# Sharecode

Open-source code repository for my Sharecode app, built with Base44.

## Source code

The app's code has not been synced from Base44 yet. To publish it here, open Sharecode in Base44, select the GitHub icon, choose **Connect to GitHub**, authorize Base44, then select **teddy19437539/sharecode** and start the code sync.

Base44's guide: [Connect a Base44 app to GitHub](https://base44.com/blog/base44-github-integration).

After the first sync, this repository will contain the app source and its version history. Review the files and remove any secrets or private data before publishing them.
